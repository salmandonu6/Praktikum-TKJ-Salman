SISTEM INFORMASI PENGELOLAAN GUDANG ALAT RUMAH TANGGA - SURYA KENCANA
PHP Native + MySQL (XAMPP)

CARA MENJALANKAN
1. Copy folder Aplikasi_gudang_surya_kencana ke  C:\xampp\htdocs\Aplikasi_gudang_surya_kencana
2. Nyalakan Apache dan MySQL di XAMPP
3. Buka http://localhost/phpmyadmin -> Import -> pilih gudang_surya_kencana.sql
4. Buka http://localhost/Aplikasi_gudang_surya_kencana
